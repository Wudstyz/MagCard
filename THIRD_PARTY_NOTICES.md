# Mentions tierces

MagCard embarque ou s'appuie sur les bibliothèques suivantes.

| Bibliothèque | Licence | Usage |
|---|---|---|
| [hidapi](https://github.com/libusb/hidapi) / [hid (Python)](https://pypi.org/project/hid/) | BSD / HIDAPI | Communication USB HID avec le lecteur MSR605X |
| [pywebview](https://github.com/r0x0r/pywebview) | BSD-3-Clause | Fenêtre native macOS autour de l'interface web |
| [PyInstaller](https://pyinstaller.org/) | GPL-2.0 (avec exception pour les programmes empaquetés) | Construction de l'application autonome |
| [Pillow](https://python-pillow.org/) | HPND | Génération de l'icône de l'application (outil de build uniquement) |

"MSR605X" est une désignation du fabricant de ce modèle de lecteur de cartes ; ce projet n'est affilié à, ni approuvé par, aucun fabricant de lecteurs de cartes. Les marques citées appartiennent à leurs propriétaires respectifs.
